# Nano-Referenzdokumentation

Diese Dokumente wurden unverändert aus `FY_Controller_Motor/docs/UART/` bzw. `FY_Controller_Motor/docs/System/` des Branches `feature/FY_ESP32_Port` kopiert. Sie dokumentieren das bestehende **Nano-Verhalten**; die ESP32-Umsetzung ist noch unvollständig.

Die aktuelle ESP32-Implementierung wird **modulnah** unter `lib/UART/UART.md` und `lib/Motor/Motor.md` beschrieben. Unterschiede zur Nano-Referenz sind bei der Portierung dort zu erfassen.

Der separate Command-Spickzettel liegt unter `src/UART_Command_Spickzettel.md`.

Dokumentationsregel: Referenz nicht unbemerkt umschreiben; bei fachlichen Änderungen zunächst Originalverhalten und ESP32-Delta dokumentieren. Issue #162.
