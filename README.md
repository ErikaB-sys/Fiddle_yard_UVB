### Documentation concept
Investigate a documentation workflow combining:
- **Mermaid** for flowcharts, state machines and software architecture diagrams, preferably stored as source in the repository and rendered where possible.
- **Doxygen** for generating technical source-code documentation from structured comments in the C/C++ code.
- **GitHub/Markdown** as the central, version-controlled documentation layer.

The goal is to keep diagrams and technical documentation close to the actual source code and maintainable together with the project.
